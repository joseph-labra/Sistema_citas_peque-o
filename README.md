# Sistema de Citas

Este proyecto es una API REST desarrollada con Java y Spring Boot para la gestión de citas médicas. Permite administrar pacientes, médicos, recepcionistas y citas, realizando operaciones CRUD para registrar, consultar, actualizar y eliminar información.

Para este proyecto utilicé el patrón MVC para organizar la aplicación, además de Spring Data JPA, Hibernate, DTOs, validaciones y PostgreSQL. La idea fue practicar el desarrollo de APIs REST con Spring Boot y trabajar con una aplicación dividida en diferentes capas.
