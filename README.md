# Gestión de Pedidos

Este proyecto es una API REST desarrollada con Java y Spring Boot para la gestión de pedidos. Permite administrar clientes, productos, categorías, pedidos, pagos y envíos, realizando operaciones CRUD para registrar, consultar, actualizar y eliminar información.

Para este proyecto utilicé el patrón MVC para organizar la aplicación, además de Spring Data JPA, Hibernate, DTOs, validaciones y PostgreSQL. La idea fue practicar el desarrollo de APIs REST con Spring Boot y trabajar con una aplicación dividida en diferentes capas.
