# Gestión de Pedidos

Este proyecto es una API REST desarrollada con Java y Spring Boot para gestionar pedidos. Permite administrar clientes, productos, categorías, pedidos, pagos y envíos mediante diferentes endpoints.

Para este proyecto utilicé el patrón MVC para organizar la aplicación, además de Spring Data JPA, Hibernate, DTOs, validaciones y una base de datos PostgreSQL. La idea fue practicar el desarrollo de APIs con Spring Boot y tener una mejor separación entre las diferentes partes de la aplicación.
